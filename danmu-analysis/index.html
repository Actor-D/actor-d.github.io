B 站弹幕文本分析

以 B 站《社会学与经济学》系列视频为对象，自建爬虫采集弹幕，用词典法做情感打分，自创「传播效果指数」衡量传播力， 并对互动指标做相关性与回归分析。

44 个视频 99,590 行原始弹幕 81,278 条唯一弹幕 38,502 名用户 r = 0.922 传播指数 ↔ 播放量

结论摘要

情感分布：正面 54.55%、负面 40.97%、中性 4.48%（均值 0.47，总体偏正面）。 传播效果指数与播放量相关系数 r = 0.922，与点赞 0.799、收藏 0.749、评论 0.747。 点赞数对 UP 主粉丝数回归的 R² = 0.376，说明粉丝量只能解释约三分之一的点赞差异。

数据质量说明：原始统计 99,590 行中含 8 个视频被重复采集（去重代码写了但未重新赋值）与 8 行表头混入， 去除后真实唯一弹幕为 81,278 条，约占原始的 82%。此外主题提取实际用的是「视频标题」上的 NMF， 并非弹幕的 LDA 主题发现，报告与作品集页面均已如实标注。

如何复现

四个 Notebook 通过 CSV 产物串联，任一环节可单独重跑：

Crawler-blili.ipynb        → bvnumber.csv / video.csv / b站弹幕集合/*.csv
词云＋处理结果.ipynb        → processed_danmu.csv（分词列）
情感得分汇总.ipynb          → sentiment_analysis_results.csv
分析.ipynb                 → 相关性 / 回归 / NMF 结果

依赖：pandas、numpy、jieba、nltk、wordcloud、scikit-learn、scipy、seaborn、selenium、beautifulsoup4。
