# Actor.D 的个人主页

一个支持中英文切换、无需构建工具并可直接部署到 GitHub Pages 的响应式个人主页。

当前版本采用暖色编辑式视觉系统，以纸张质感、克制的几何图形和珊瑚色强调构成统一风格；同时包含双语切换、响应式导航、滚动反馈、交互式项目界面、业务流程、工程架构和 API 展示。

页面结构（首页总览 + 详情页）：

- `index.html` 个人主页总览：Hero、关于我、**项目预览卡**（浙就来：部分内容 + 链接完整案例）、**论文预览卡**（Fair-DQN：关键数据 + 链接完整论文）、学习经历、联系我
- `project.html` 项目详情页：浙就来完整案例（业务问题/方案、交互式界面预览、订单流程、系统架构、工程拆解与 REST API 展示）
- `research.html` 论文详情页：Fair-DQN 毕业论文展示（摘要、核心发现、模型、图表、实验、局限展望）

三个页面共用同一套暖色编辑式视觉系统与双语切换（浏览器语言自动选择并记忆），详情页底部互相链接（回到主页 / 项目案例 / 研究论文）。

## 发布到 GitHub Pages

1. 在 GitHub 新建一个公开仓库，例如 `myweb`。
2. 在本文件夹运行：

```powershell
git add .
git commit -m "Create bilingual personal website"
git remote add origin https://github.com/你的用户名/myweb.git
git push -u origin main
```

3. 打开仓库的 **Settings → Pages**。
4. 在 **Build and deployment** 中选择 **Deploy from a branch**，分支选择 `main` 和 `/ (root)`，然后保存。
5. 稍等片刻，通过 `https://你的用户名.github.io/myweb/` 访问网站。

如果仓库名称是 `你的用户名.github.io`，主页地址就是 `https://你的用户名.github.io/`。
