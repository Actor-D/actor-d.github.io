项目案例

全栈 Web 应用

浙就来

面向浙江大学校园场景的配送服务平台

项目围绕校园外卖与物品配送需求，连接用户认证、多步骤下单、地址管理、支付选择和订单查询，形成完整的前后端业务流程。

Vue 3 Vite Pinia Flask SQLAlchemy SQLite JWT
01

业务问题

校园配送信息分散，履约流程缺少统一入口

学生在外卖、快递与校内物品配送场景中，需要重复沟通取件位置、收货地址、费用和进度，信息容易遗漏。

02

产品方案

把身份、订单、地址与支付串成一条数字化链路

平台围绕学生身份构建统一账户，用分步表单降低下单复杂度，并通过订单状态和个人中心沉淀完整服务记录。

核心业务流

从需求提交到订单履约

01 INPUT

提交需求

填写物品名称、取件柜与备注，支持加急配送。

02 LOCATION

确认地址

选择常用地址或输入新地点，绑定当前用户。

03 PAYMENT

选择支付

按普通或加急规则计算现金与积分费用。

04 STATUS

追踪订单

查看订单列表、详情、状态并支持再次下单。

核心功能

从登录到履约的完整体验

  • 学号注册登录、密码加密与受保护路由
  • 订单创建、地址选择、加急费用与多种支付方式
  • 个人资料、常用地址、积分和订单状态管理
  • 订单图片上传与基于用户的 API 权限控制
