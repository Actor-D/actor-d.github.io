猫狗图像分类

不使用预训练权重，用 Keras 逐层搭建 4 个卷积块的网络，在 128×128 输入上完成猫狗二分类； 随后加入自行爬取的 2,000 张动漫猫狗做对照实验。

25,000 张实拍图 2,000 张自爬动漫图 5.11M 参数 测试准确率 95.12%（基线）

对照实验结论

指标变体 A · 纯真实图变体 B · 真实 + 动漫
图像总量25,00027,000（+2,000）
实际训练轮数3040（配置 60，早停触发）
训练准确率96.39%94.65%
验证准确率95.56%94.33%
测试准确率95.12%93.93%
两个必须说明的问题：① 加入动漫数据后，真实图像上的准确率下降约 1.2 个百分点； ② 变体 B 的测试集里混入了约 200 张动漫图，因此 93.93% 是「真实 + 动漫」的混合精度， 与变体 A 的 95.12% 并非同一口径。课件曾把 94.32% 与 93.93% 当作两个模型对比， 实际上两者都属于变体 B（前者验证集、后者测试集）。动漫图上的收益从未单独测量。

关键配置

输入尺寸     128 × 128 × 3
网络结构     Conv2D(32/64/128/256, 3×3, valid) + BatchNorm + MaxPool + Dropout(0.2)
             → Flatten → Dense(512) → BatchNorm → Dropout → Dense(2, softmax)
参数量       5,112,514（可训练 5,110,530）
优化器       Adam，loss = binary_crossentropy，batch = 32
数据增强     旋转 15°、缩放 0.2、水平翻转、剪切 0.1、宽高平移 0.1、fill_mode=reflect
回调         ReduceLROnPlateau(val_accuracy, patience=10, factor=0.9)
             EarlyStopping(val_loss, patience=10, restore_best_weights=True)
