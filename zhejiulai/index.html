FULL-STACK PROJECT · 源码与使用说明

浙就来

面向浙江大学校园场景的配送服务平台（最终版）：学号注册登录、双模式下单（代取外卖 / 代送物品）、地址簿、 现金与积分双币支付、订单跟踪，以及基于大模型的 AI 助手问答。

前端 Vue 3 单页应用 + 后端 Flask REST 服务，SQLite 落库，并接入 scikit-learn 计价模型与 DeepSeek 对话助手： 23 条路由（21 条受保护）、31 个 REST 接口（27 个需令牌）、7 张数据表、 10 万行训练数据。

Vue 3.5Vite 6Vue Router 4Pinia 3 vue-i18nElement Plusaxios Flask 3Flask-SQLAlchemyPyJWT scikit-learnpandasDeepSeekSQLite

如何运行

需要 Node.js 18+ 与 Python 3.10+。先启动后端（默认 5000 端口）：

cd server
python -m venv .venv
source .venv/bin/activate    # Windows: .venv\Scripts\activate
pip install -r requirements.txt

# 密钥从环境变量读取（仓库中不含任何密钥）
export SECRET_KEY="$(python -c 'import secrets;print(secrets.token_hex(32))')"
export DEEPSEEK_API_KEY="sk-..."   # 可选：不配置则 AI 助手不可用

python app.py

再启动前端（默认 5173 端口）：

cd client
npm install
npm run dev

首次启动会自动建库（server/zju_delivery.db），没有预置测试账号——请先注册：学号为 10 位数字，手机号为 11 位（1[3-9] 开头）。

两个技术亮点

机器学习计价：model.pkl 由 scikit-learn 基于 10 万行delivery_data.csv 训练，输入尺寸 / 距离 / 是否加急，输出积分配送费， 在创建外卖订单时实时调用。

AI 助手：通过 OpenAI 兼容协议接入 DeepSeek，配约 700 字中文 system prompt， 会话与消息持久化到 chat_sessions / chat_messages 两张表。

业务规则

双向计价：普通 ¥5 / 50 积分，加急 ¥7 / 70 积分（外卖订单的积分价由模型预测， 物品代送固定 10 积分）；支付时在事务中原子扣减积分。 密码以 PBKDF2-SHA256 加密，令牌为 HS256 且 24 小时过期；地址与订单查询强制携带 user_id 隔离； 上传仅允许 png/jpg/jpeg/gif 且不超过 5MB。
