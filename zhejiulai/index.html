FULL-STACK PROJECT · 源码与使用说明

浙就来

面向浙江大学校园场景的配送服务平台，覆盖学号注册登录、四步下单、地址管理、现金与积分双币支付、订单查询的完整闭环。

前端 Vue 3 单页应用 + 后端 Flask REST 服务，数据落库 SQLite：18 条前端路由（16 条受保护）、17 个 REST 接口、3 张数据表。

Vue 3.5Vite 6Vue Router 4Pinia 3 Element PlusaxiosFlask 3Flask-SQLAlchemy PyJWTSQLite

如何运行

需要 Node.js 18+ 与 Python 3.10+。先启动后端（默认 5000 端口）：

cd server
python -m venv .venv
source .venv/bin/activate    # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python app.py

再启动前端（默认 5173 端口）：

cd client
npm install
npm run dev

首次启动会自动建库（server/zju_delivery.db），没有预置测试账号——请先注册：学号为 10 位数字，手机号为 11 位（1[3-9] 开头）。

业务规则

双向计价：普通 ¥5 / 50 积分，加急 ¥7 / 70 积分，固定 1 元 = 10 积分； 密码以 PBKDF2-SHA256 加密，令牌为 HS256 且 24 小时过期；地址与订单查询强制携带 user_id 隔离； 上传仅允许 png/jpg/jpeg/gif 且不超过 5MB。
